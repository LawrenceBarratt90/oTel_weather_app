# --- App ---

httpx                                      # HTTP client for the weather API (auto-traced)

opentelemetry-instrumentation-langchain    # auto-traces LangChain/LangGraph + LLM calls (gen_ai.* attributes)
opentelemetry-instrumentation-httpx        # auto-traces outgoing httpx HTTP calls
